# Lumen

The design system of slashome. One implementation, used the same way from React, Vue, Svelte or plain HTML.

## Two floors

- **Floor 0, CSS.** Tokens, and every component without state: `.lu-button`, `.lu-icon-button`, `.lu-badge`, `.lu-input`, `.lu-native-select`, `.lu-switch`, `.lu-kbd`, the page states, `.lu-markdown`, `.lu-data-table`, `.lu-mark`, and the utilities `.lu-visually-hidden`, `.lu-truncate`, `.lu-line-clamp`, `.lu-spin`. The data table sorts with `sortRows` and `storedSort()`, no element needed. BEM classes in cascade layers: an application overrides them without `!important`, and they work without JavaScript.
- **Floor 1, Lit.** Custom elements, only for what has state: `<lu-dialog>`, `<lu-sheet>`, `<lu-confirm-dialog>`, `<lu-tooltip>`, `<lu-hover-card>`, `<lu-select>` and `<lu-multi-select>` with their `<lu-option>`, `<lu-segmented>`, `<lu-toaster>`, `<lu-markdown>`, `<lu-highlight>`, `<lu-drag-area>` with `<lu-draggable>` and `<lu-drop-zone>`, `<lu-icon>`. The platform first: `<dialog>`, the popover API.

## Install

```sh
pnpm add @slashome/lumen
```

```js
import '@slashome/lumen/lumen.css'
import '@slashome/lumen'
```

## Theme

Two colors, set on `:root` at run time; every other shade derives from them, in light and dark.

```css
:root {
  --lu-theme-primary: #3760c9;
  --lu-theme-secondary: #3760c9;
}
```

Dark mode follows `data-appearance="dark"` on the root element, or the system when the attribute is absent.

## React

```tsx
import { Button, Dialog, toast, Toaster } from '@slashome/lumen/react'
```

The adapter keeps React's idioms: `open` and `onOpenChange`, `value` and `onValueChange`.

## Vue

```ts
import { isLumenElement } from '@slashome/lumen/vue'

vue({ template: { compilerOptions: { isCustomElement: isLumenElement } } })
```

```vue
<lu-select :value="status" @lu-value-change="status = $event.detail.value">
  <lu-option value="todo">To do</lu-option>
</lu-select>
```

## Plain HTML

```html
<button class="lu-button lu-button--outline">Cancel</button>
<lu-tooltip content="Copy the command"><button class="lu-icon-button"><lu-icon name="copy"></lu-icon></button></lu-tooltip>
```

## Icons

`<lu-icon name="close">` draws a semantic name mapped to an Iconify id, embedded at build time: no request at run time. An application adds its own names with `lumen-icons <mapping.json> <output.ts>` and `registerIcons()`.

## Events

Every event is a `CustomEvent` named `lu-*`, bubbling and composed: `lu-open-change`, `lu-value-change`, `lu-selected-change`, `lu-confirm`, `lu-navigate`, `lu-drag-end`, `lu-open`.
